## Create Environment in Anaconda

Here we take Anaconda on Windows 10 for example. 

- After clicking Anaconda, a main window will show up. On the left panel, there are tabs for 'Home', 'Environments', 'Learning' and 'Community'. All available software are listed in the main area, and there is a 'Applications on' combobox on top. This combobox shows which environment you are using. e.g. I already chose an environment called 'conda38_3' in the screeshot. But when you start Anaconda, an environment called 'base' is the one shows there.
<img src="../image/anaconda_0.PNG">


- To create a new environment, click 'Enviroments' tab. Before creating any new environments, you will only see 'base (root)' environment which has a small triangle arrow next to it. Click 'Creat' button on the bottom, a 'create new environment' window will popup. Enter a name for your desier environment and click 'create'. The screenshot shows an environment 'conda38_3' is created. Click the environment you would like to use and you will see the small triangle arrow move to the environment you clicked.
<img src="../image/anaconda_1.PNG">


- Click the small triangle arrow to go to Terminal. Install or update the desired package in the Terminal. Click the 'Update index...' button on the top of package list. You can check the versions of packages in the package list also.
